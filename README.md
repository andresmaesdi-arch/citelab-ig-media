# citelab-ig-media

Public, direct-URL media host for The Cite Lab Instagram Graph API publishing.

Instagram needs HTTPS URLs with no query string that its servers can fetch. Files in this repo are served as:

`https://raw.githubusercontent.com/andresmaesdi-arch/citelab-ig-media/main/posts/<post-slug>/<file>`

This repo is only for temporary or reusable publish assets. It is not a product codebase. Do not put secrets, captions with private data, or credentials here.
